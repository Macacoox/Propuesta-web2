# Fuentes del PDF

Copias de DM Sans y Space Grotesk (subconjunto latino, formato WOFF) para
`@react-pdf/renderer`, que no admite WOFF2. Son las mismas tipografías que usa
la web. Licencia SIL Open Font License 1.1 (ver archivos LICENSE-*).

Origen: paquetes `@fontsource/dm-sans` y `@fontsource/space-grotesk` v5.
